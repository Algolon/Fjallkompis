# Mobile pilot — vNext shell (Today · Map · Guide · Plan · Settings)

A 20–30 minute test of the new five-tab structure on a real phone. You are
testing where things LIVE, not how they look — say out loud where you expect
something before you look for it.

## Install

- **Live URL:** https://algolon.github.io/Fjallkompis/
- **Android (Chrome):** open the URL → the app offers "Install Fjällkompis",
  or use ⋮ → *Add to Home screen* → *Install*. Open it from the home screen
  afterwards so it runs as a standalone app (no address bar).
- **Update/refresh:** reopen the app while online; when a toast offers an
  update, accept it. (No toast = you are already current.)
- **Offline assets:** Settings → *Offline maps* → download the basemap
  (~6 MB; terrain and satellite are optional and larger). Settings → *Trail
  readiness* shows what is stored.
- **Reset personal test data:** Settings → *Backup & restore* → *Reset local
  data*. This clears plan, packing, trip items and stored documents — the
  app itself stays installed, so you can start over without reinstalling.

## Test scenario (20–30 min)

1. **Orientation (no instructions):** open the app and look around for two
   minutes. Say what you think each of the five tabs is for.
2. **Prepare a trip:** create a Day plan (Plan → Day plan), check the
   packing list (Plan → Packing) and mark a few items.
3. **Find trail information:** how long is stage 3, and does Sälka have a
   shop? (Expected home: Guide.)
4. **Save a transport item:** find the bus from Nikkaluokta (Guide →
   Transport) and add it to your trip. Check where it ended up.
5. **Open the route on the Map:** from Today, use *View route*; from a
   stage, use *View on map*.
6. **Reopen offline:** enable flight mode, close the app fully, reopen it.
   Navigate through all five tabs. Note anything that breaks or looks
   dishonest about what is/isn't available.
7. **Tonight & membership:** on Today (On route), open Tonight's stop and
   the STF membership card.

## Feedback questions

1. Where did you expect to find each piece of information — and where was it?
2. Where did you hesitate between Guide and Plan?
3. Could you reach the relevant information for *today* within a few seconds?
4. Which parts felt duplicated?
5. Which action did you expect but not find?
6. Which information took more space than it deserved?
7. Did you trust the freshness/source information (verification dates,
   content version, caveats)?
8. Did the app behave as a standalone app (install, reopen, offline)?
9. What would you miss first during a real hiking day?
10. What must change before the next test?

Report issues with Settings → *Copy diagnostic summary* (technical facts
only — versions, platform, offline asset status; never personal data) pasted
into your message.
